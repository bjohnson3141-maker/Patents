The most advanced ML model I have worked on was a set of edge-deployed hybrid object recognition and tracking algorithms. These algorithms utilized advanced mathematics to supplement and improve YOLO. 

The first algorithm was named TIM or Tracking Invariant Morphology. This algorithm used elastic shape analysis to find objects that marked them as manned or unmanned vehicles in various levels object concealment and noise applied to single images. This effort resulted in a patent application and publication. See US-20260038136-A1.

The second algorithm was named LISA or Light Informed Shape Analysis. This algorithm continued our work on TIM but was applied to a sequence of frames. We demonstrated the ability to continuously detect and track objects that YOLO missed due to image noise, camera jitter, and/or object concealment. This resulted in a patent application and publication. See US-20260087792-A1.

The third algorithm was named BLISS or Body Language Informed Shape Scanning. This algorithm was built upon LISA but was applied specifically to the detection, classification, and tracking body language from a person’s extremities. This resulted in a patent application, but it has not been published yet. This work was presented at the 2026 Navy Applications of Machine Learning conference.

The fourth algorithm was named DART or Detecting All Relevant Threats. This algorithm was built upon our previous algorithms and is meant to be a lightweight, edge deployed threat detection and classification system for security cameras. This resulted in a patent application, but it has not been published yet.

I've shipped models that served to capture contracts with the government in response to the Golden Dome executive order.

The Golden Dome effort was performed in response to a request for proposals from the Department of War. We had the flexibility needed to innovate as we saw fit to produce the best solution possible. We were handed a set of requirements, a budget, and a set of deadlines. Our team then proceeded to operate within those constraints to produce a tiny neural network-based computer vision system deployed on a small satellite launched by a subcontractor. Data was collected and objects were detected and classified. The results captured were then used to make the case for Booz Allen’s response to the proposal requests. Furthermore, our innovations served as the basis for a patent application which was published by the US PTO this year (see US-20260065640-A1).
